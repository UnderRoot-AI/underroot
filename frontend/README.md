# Smart Soil Health Frontend

React + Vite frontend for the Smart Soil Health Detection and Decision Support System.

## Main flow

- Soil Test → hardware/manual values → Soil Analyzer.
- Soil Analyzer → parameter status + graph + crop model + fertilizer model.
- Soil Report → report history only.
- Upload Soil Report → OCR → Verify Data → Soil Analyzer.
- Government Resources → active entries managed by the developer account.
- Header language selector → English / Hindi / Gujarati.
